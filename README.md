# Yapılacaklar

Supabase ile çalışan, tek dosyalık basit bir yapılacaklar listesi.

- Sayfa: `Yapilacaklar.html` (GitHub Pages ile yayında)
- Veritabanı şeması: `supabase/migrations/`
- Her kullanıcı yalnızca kendi görevlerini görür (Row Level Security).

Sayfadaki Supabase anahtarı herkese açık olacak şekilde tasarlanmış "publishable" anahtardır; veriler RLS kurallarıyla korunur.
